# stockroom

Claude Code plugin marketplace for marketplace-operator skills by [Jeremy Peronto](https://jeremyperonto.com) — storefront audits, seller economics, and the operating work behind e-commerce.

## Install

```
/plugin marketplace add jeremyperonto/claude-plugins
/plugin install walk-the-store@stockroom
```

Enable auto-updates for this marketplace in `/plugin` → Marketplaces, and new versions install themselves. Updates ship only on version bumps, never on raw commits.

## Skills

| Plugin | What it does | Topics |
|---|---|---|
| [walk-the-store](https://jeremyperonto.com/walk-the-store/) | Audits your storefront by shopping it as a qualified customer persona — findings as work orders, screenshots as exhibits, measurement built in | marketplace-operations · e-commerce, storefront-audit, conversion, merchandising |

More operator skills are in progress; they land here first.

## Trust posture

Plugins in this marketplace are markdown instructions only — no hooks, no MCP servers, no executables. What you install is what you can read.
